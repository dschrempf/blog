# Blog typography: Inter / Inter Tight, and what artificialanalysis.ai actually uses

Date: 2026-06-08

## Context

Goal: improve the blog's interface by adopting Google Fonts **Inter** (body) and
**Inter Tight** (headings). The user referenced <https://artificialanalysis.ai/models>
as the desired headline aesthetic ("light, not bold").

## What was implemented on the blog

Following the Skeria theme's "only use static content" rule (no CDN), the fonts are
**self-hosted** as variable woff2 files (latin subset, full 100–900 weight axis):

- Files in `hugo/themes/skeria/static/webfonts/`:
  - `inter-latin-wght-normal.woff2`, `inter-latin-wght-italic.woff2`
  - `inter-tight-latin-wght-normal.woff2`, `inter-tight-latin-wght-italic.woff2`
  - Source: jsDelivr Fontsource (`inter:vf`, `inter-tight:vf`).
- New `hugo/themes/skeria/static/css/fonts.css` with four `@font-face` rules
  (`font-weight: 100 900; font-display: swap;`).
- Linked from `hugo/themes/skeria/layouts/_default/baseof.html` in the "Fonts" head
  section (previously "None.").
- `skeria.css`: `html` body font → `'Inter', system-ui, sans-serif`;
  `h1–h6` → `'Inter Tight', system-ui, sans-serif`.

Heading weight/tracking was iterated: started 600, user found it too bold, set to 400,
then the user manually set **`font-weight: 300` + `letter-spacing: -0.02em`**.

## Investigation: what artificialanalysis.ai actually uses

Inspected the live site's raw HTML and CSS bundles (`/_next/static/css/*.css`) plus the
real heading elements on `/models`. Findings:

### It does not use Inter

The site is Tailwind + `next/font`. Font stack:

- `--font-sans: "suisseIntl"` → **Suisse Intl** (commercial Swiss grotesque) — UI/body.
- `--font-serif: "victorSerifBasic"` → commercial serif — used for many headings.

So the aesthetic comes from Suisse Intl / a refined serif, **not** Inter. Inter Tight is
a passable open grotesque substitute but is not what the site uses.

### Exact heading settings

Preflight resets all headings (`h1…h6 { font-size: inherit; font-weight: inherit }`),
so each heading's appearance comes entirely from utility classes.

| Element | Font | Size / line-height | Weight | Letter-spacing |
|---|---|---|---|---|
| Page title `h1` (`text-4xl`) | sans — Suisse Intl | `2.25rem` / `2.5rem` (~1.11) | **400 (normal)** | **normal (none)** |
| Section head `h3` (`text-2xl font-brand-serif font-medium`) | serif (victorSerifBasic) | `1.5rem` / `2rem` | **500 (medium)** | normal |
| Sub-head `h3` (`text-xl font-brand-serif`) | serif | `1.25rem` / `1.75rem` | 400 (normal) | normal |

Relevant Tailwind utility definitions confirmed in the bundles:

- `.text-4xl{font-size:2.25rem;line-height:2.5rem}`
- `.text-2xl{font-size:1.5rem;line-height:2rem}`
- `.text-xl{font-size:1.25rem;line-height:1.75rem}`
- `.font-medium{font-weight:500}`, `.font-light{font-weight:300}`, `.font-normal{font-weight:400}`, `.font-semibold{font-weight:600}`
- `.tracking-tight{letter-spacing:-.025em}`, `.tracking-tighter{letter-spacing:-.05em}`
- `.font-brand-serif{font-family:var(--font-serif),Georgia,Cambria,serif}`

### What produces the "airy, not-bold" feel

1. **Weight 400–500, never bold.** Size carries the hierarchy, not weight.
2. **Normal letter-spacing.** The `tracking-tight` (−0.025em) / `tracking-tighter`
   (−0.05em) utilities exist but are **not applied** to the page/section headings — the
   headings are not crunched.
3. **Generous line-height** (~1.1–1.33).

Caveat: inside article/markdown `.prose` content, the Tailwind Typography plugin sets
`h1` to `font-weight: 800` — heavy. That's the prose default, not the clean UI look the
user referenced.

## Recommendation vs. current blog CSS

The user's manual `font-weight: 300` + `letter-spacing: -0.02em` is **lighter and tighter**
than artificialanalysis. To match their look more faithfully:

```css
h1, h2, h3, h4, h5, h6 {
  font-family: 'Inter Tight', system-ui, sans-serif;
  font-weight: 400;       /* or 500 for a touch more presence */
  letter-spacing: normal; /* drop the -0.02em */
}
```

If matching the site matters more than using Inter specifically, the closest **open**
substitutes for Suisse Intl would be **Mona Sans** or **Hanken Grotesk**, rather than
Inter Tight.
